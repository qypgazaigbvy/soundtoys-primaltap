## Overview

Soundtoys PrimalTap captures the unique character of the Lexicon Prime Time digital delay, delivering that early digital crunchiness and the distinctive doubling and slap-back effects it became known for.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys PrimalTap** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Prime Time Model** | Circuit-accurate emulation of the Lexicon Prime Time delay unit |
| **Multiply Feature** | Unique delay time multiplication for cascading echo textures |
| **Lo-Fi Character** | Early digital aliasing and bit reduction for authentic vintage color |
| **Doubling Mode** | Tight stereo doubling with minimal smear for vocal and guitar enhancement |
